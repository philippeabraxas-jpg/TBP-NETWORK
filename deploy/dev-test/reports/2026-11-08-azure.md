## What it found

| # | Finding | State |
|---|---|---|
| 1 | The machine that builds the cell needs a C compiler: without `gcc` the build fails with `undefined: pkcs11.Attribute` | fixed (the script says so before building; the guides list it) |
| 2 | A new Azure subscription can be refused some sizes and a whole region (*"not accepting new customers"*), which the template validation does not show | documented in the Azure guide, with a free test of the region |
| 3 | The live console drew nothing that arrived after the page was opened (`Requests (0)`), because the page read each update wrapped; a reload showed it | fixed; the browser test now posts a request after the page is open |
| 4 | A token lives 30 to 60 s; "the same token again" gave `stale-token` after three minutes. An approval from `m1 sign` gave `plan-deviation` the second time | the guide now says so |
| 5 | An error message of `m2 mode` was in French in the middle of English output | the quorum messages of the mode path are in English |
| 6 | One `opa-timeout` in 67 decisions. The cell gives OPA a strict 5 ms budget (spec §9.1); a minimal exchange with OPA took under 1 ms in 200 of 200 tries at rest, so the cause of this one is **not established** (OPA's evaluation, the queue in front of it, or a pause of the cell itself) | open; worth counting under load |
| 7 | The cell's decision takes about 550 ms with a spread of 3 ms over 60 requests (an allowed one about 780 ms), and `pepd` takes about 260 ms for a valid token against about 7 ms for a refusal, although the code writes the same journal leaf in both. The very narrow spread points to a fixed wait rather than computation | open; **not explained**: to measure by step inside `pepd` and the cell |

## What this does not say

One person, one run, a few dozen requests per measure, no load. The 550 ms and 260 ms are what this setup gave, not a property
of Azure, and the explanations marked "not established" or "not explained" are not claims. The same run on AWS, then under
load, is what the complete report is for.
